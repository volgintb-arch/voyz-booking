# Voyz Booking — мини-бронирование для гостевых домов и юрточных лагерей

Приложение для iOS, Android и браузера: гость находит юрту или номер и
бронирует с предоплатой, хозяин ведёт шахматку, брони и оплаты с телефона.
Брони и оплаты передаются в учёт **Aynes** по готовому API
(контракт `BOOKINGS_API.md`; документы проекта в этот публичный репозиторий не выкладываем).

**Сейчас это только фронтенд** (интерфейс) с демо-данными: всё работает
на телефоне, данные хранятся только на этом устройстве. Сервер подключим
следующим этапом.

## Где посмотреть

| Что | Где |
|---|---|
| **Android** — тестовая сборка (APK) | **Releases → android-latest**: скачайте `voyz-booking.apk` на телефон и откройте |
| **iOS** — проект Xcode в папке `ios/` | для установки на iPhone нужен аккаунт Apple Developer (TestFlight) |
| Предпросмотр по ссылке (тот же код, без установки) | https://volgintb-arch.github.io/voyz-booking/ |

Отдельного сайта нет: приложения iOS и Android и предпросмотр по ссылке —
один и тот же код. Ссылка нужна, чтобы сразу смотреть изменения на любом
телефоне, пока нет сборки в TestFlight.

**Дизайн** — в стиле Voyz: белый фон, неоновый лайм, тёмно-оливковые
панели, шрифты Nunito и Montserrat (встроены в приложение, работают без
интернета), поля и кнопки-«таблетки», плавающее нижнее меню.

## Что умеет

**Гость**
- поиск по датам, числу гостей и месту (Сон-Куль, Иссык-Куль, Нарын…);
- карточка объекта: описание, удобства, правила отмены, карта;
- свободные номера и юрты с ценой за весь срок (сезонные цены, доплата за гостя, минимальный срок);
- бронь с согласием на обработку данных, предоплата по QR / карте / переводу или оплата на месте;
- «Мои брони» с отменой по правилам объекта.

**Хозяин**
- шахматка: юрты/номера × даты, цвета — предоплата есть, без предоплаты, ждёт подтверждения, гость на месте, Booking.com/Airbnb (iCal), закрыто;
- бронь из WhatsApp или звонка — нажатием на свободную клетку; двойная продажа одной юрты невозможна — приложение показывает, чем занято место;
- подтвердить / отклонить, заселить, выселить, «не заехал», отметить оплату наличными или возврат;
- готовое сообщение гостю в WhatsApp и Telegram;
- настройки: цены по категориям и сезонам, предоплата и правила отмены, закрытые даты, ссылки iCal, ключ Aynes и очередь отправки.

**Продвижение** (Хозяин → кнопка «Поделиться» на шахматке или Настройки → Продвижение)
- ссылка на бронь с меткой источника (Instagram, WhatsApp, Telegram…) и, по желанию, с уже выбранными датами; в мессенджерах показывается карточкой с картинкой, названием и ценой;
- QR-постер A4 на трёх языках: печать или скачивание QR;
- виджет для сайта хозяина — одна строка кода: плавающая кнопка «Забронировать» или форма брони внутри страницы;
- «Откуда брони» — сколько пришло по каждой ссылке; источник уходит в Aynes полем `channel`.

**Предоплата по QR хозяина** (решение D-001, `docs/DECISIONS.md`)
- хозяин загружает QR из банка и реквизиты, выбирает, сколько часов держать бронь;
- гость видит сумму, QR, реквизиты и номер брони для комментария, жмёт «Я оплатил»;
- хозяин жмёт «Деньги пришли» — оплата записывается, бронь подтверждается;
- не оплатили вовремя — бронь снимается сама, юрта снова свободна.

**Работа без интернета.** Всё сохраняется на телефоне. Запросы в Aynes
копятся в очереди и уходят, когда появится связь; повтор ничего не задваивает.

**Языки:** русский, кыргызский, английский — переключатель вверху экрана.
Кыргызские тексты — черновик, их нужно вычитать носителю языка.

## Как устроено (для разработчиков)

- React 19 + TypeScript + Vite; офлайн через service worker.
- Rollup закреплён на 4.44.1 (`overrides` в `package.json`): в 4.64 сборка react-dom шла ~4 минуты вместо 3 секунд.
- iOS и Android — оболочка **Capacitor 7** вокруг того же веб-кода (папки `ios/`, `android/`).
- Один код работает в браузере, в нативном приложении и в Telegram Mini App.
- Деньги — целые числа в минимальных единицах (тыйыны) с валютой; даты заезда/выезда — календарные дни в поясе объекта (Бишкек, +6).
- Тексты интерфейса — только в `src/i18n/` (ru, ky, en), не в экранах.

```
src/
  domain/        цены, занятость, деньги, даты — чистая логика с тестами
  data/          демо-данные, состояние, сохранение на устройстве
  integrations/  контракт с Aynes (PUT брони и оплаты, очередь)
  screens/       экраны гостя и хозяина
  i18n/          тексты на трёх языках
```

Команды:

```bash
npm install
npm run dev        # локальный запуск
npm run typecheck && npm run lint && npm test
npm run build      # сборка в dist/
npm run cap:sync   # сборка + копирование в ios/ и android/
```

Сборки на GitHub Actions:
- **Web** — проверки и публикация на GitHub Pages при каждом изменении в `main`;
- **Android** — APK в релиз `android-latest`;
- **iOS** — проверочная сборка под симулятор (запуск вручную, macOS дороже по минутам).
