# Сценарий демо (10–15 минут)

Подготовка за день:
- открыть сайт — разбудить сервер Render (после сна первый ответ до минуты);
- войти «Демо-входом» на компьютере (кабинет хозяина), на телефоне — гостевая часть;
- в Telegram держать открытым бот (если показываете вход через Telegram).

Демо-объекты: «Сон-Куль Айыл» и «Каракол Хаус» (демо-хозяин), «Бостери Бич» и
«Таш-Рабат» (другой хозяин).

## 1. Гость (телефон) — 4 минуты

1. Хозяин отправил ссылку в WhatsApp: показать карточку ссылки с картинкой и ценой
   (Продвижение → Ссылка → WhatsApp).
2. Гость открывает ссылку → карточка объекта: фото, правила, «Заезд/Выезд», цены.
3. Даты и гости → «Выбрать» → имя, телефон, согласие → «Забронировать».
4. Предоплата: QR и реквизиты хозяина, номер брони в комментарий, срок оплаты →
   «Я оплатил».

## 2. Хозяин (компьютер или телефон) — 5 минут

1. Шахматка: новая бронь жёлтым («ждёт подтверждения»).
2. Брони → карточка: «Гость сообщил об оплате», источник «по ссылке из WhatsApp».
3. «Деньги пришли» → бронь зелёная, у гостя «Подтверждена» (обновить «Мои брони»).
4. Внести бронь из WhatsApp вручную: нажать на свободную клетку шахматки.
   Попробовать занять уже занятую юрту — приложение не даст продать дважды.
5. Настройки → Редактировать объект: добавить юрту, переименовать.
6. Продвижение: QR-постер для печати, код виджета для сайта.

## 3. Ключевые мысли

- Деньги идут хозяину напрямую, платформа их не касается.
- Двойная продажа невозможна — защита на уровне базы данных.
- Брони и оплаты сами уходят в учёт Aynes.
- Работает на телефоне, кыргызский/русский/английский.
- Хозяин получает брони в Telegram и подтверждает кнопкой.

После демо — Настройки → «Выйти».
