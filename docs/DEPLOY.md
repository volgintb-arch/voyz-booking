# Запуск сервера (пилот)

Инструкция для владельца, шаг за шагом. Без сервера приложение работает в
демо-режиме: данные хранятся только на телефоне.

## 1. Создать Telegram-бота (5 минут)

1. В Telegram откройте **@BotFather** → `/newbot`.
2. Имя: `Voyz Booking`, адрес: например `voyz_booking_bot`.
3. BotFather пришлёт **токен** вида `123456:ABC…` — это секрет, никому не пересылайте.

## 2. Развернуть сервер на Render (15 минут)

1. Зарегистрируйтесь на https://render.com (можно через GitHub).
2. **New → Blueprint** → выберите репозиторий `voyz-booking`. Render прочитает
   файл `render.yaml` и создаст базу данных и сервер.
3. В настройках сервиса **voyz-booking-api → Environment** заполните:
   - `TELEGRAM_BOT_TOKEN` — токен из шага 1;
   - `TELEGRAM_BOT_USERNAME` — адрес бота без `@`;
   - `API_URL` — адрес сервиса, который покажет Render, например
     `https://voyz-booking-api.onrender.com/`.
4. Сохраните — сервер перезапустится и сам подключит бота.

Проверка: откройте `API_URL` + `health` — должно быть `{"ok":true}`.

Демо-данные (4 объекта): Render → сервис → **Shell** → `npm run seed`.

## 3. Переключить приложение на сервер

GitHub → репозиторий → **Settings → Secrets and variables → Actions →
Variables → New repository variable**:

- имя `VITE_API_URL`, значение — тот же `API_URL`.

Затем **Actions → Web → Run workflow** и **Android → Run workflow**.
Сайт и APK пересоберутся уже с сервером.

## Ограничения бесплатного Render

- Сервер «засыпает» через 15 минут без запросов; первый запрос после сна —
  до минуты. Фоновые задачи (снятие неоплаченных броней, iCal, сводка)
  работают, пока сервер не спит.
- Бесплатная база удаляется через 30 дней.

Для живого сезона (решение D-006) — VPS в Кыргызстане и платный тариф без сна:
тот же Docker-образ (`server/Dockerfile`), переменные из `server/.env.example`.

## Переменные сервера

Полный список с пояснениями — `server/.env.example`. Важное:

| Переменная | Что это |
|---|---|
| `DATABASE_URL` | адрес базы PostgreSQL |
| `SERVER_SECRET` | длинная случайная строка, шифрует ключи Aynes |
| `ALLOW_DEV_LOGIN` | `true` — кнопка «Демо-вход» без Telegram. Для реальных хозяев — `false` |
| `CORS_ORIGINS` | с каких адресов приложение может обращаться к серверу |
