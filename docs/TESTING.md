# Чек-лист тестирования перед демо и переездом

Отмечайте ✅ / ❌ и присылайте Claude номера пунктов с ❌ и скриншот.

## Гость
1. Поиск: даты, число гостей, фильтр по региону — цены и «Свободно» меняются.
2. Карточка объекта: картинка, «Заезд/Выезд», «Предоплата», «Номера и юрты», карта.
3. Бронь без имени / телефона / согласия — показывает ошибку.
4. Бронь на минимальный срок меньше сезонного (Сон-Куль, июль, 1 ночь) — не даёт.
5. Бронь проходит → экран предоплаты: сумма, реквизиты, срок «Оплатите до…».
6. «Я оплатил» → «Мои брони»: «хозяин проверит поступление».
7. Отмена брони гостем → статус «Отменена».
8. Ссылка `…/s/son-kul-aiyl/?src=instagram` открывает объект; бронь помечена Instagram.
9. Переключение языка RU / KY / EN на всех экранах.

## Хозяин
10. Вход через Telegram: бот отвечает «Готово», приложение входит само.
11. Новый хозяин без объектов: «Добавить объект» → объект создан, видна шахматка.
12. Редактировать объект: название, удобства, добавить/переименовать/удалить юрту.
13. Удалить юрту, у которой есть бронь, — не даёт.
14. Шахматка: нажать на свободную клетку → новая бронь сохраняется.
15. Занять занятые даты → «Это место уже занято».
16. Карточка брони: Подтвердить / Заселить / Выселить / Не заехал / Отменить.
17. «Деньги пришли» → оплата в списке, бронь подтверждена.
18. Telegram: новая бронь гостя приходит в бот с кнопками; «Подтвердить» из бота работает.
19. Неоплаченная бронь снимается после срока (Настройки → Оплата по QR → 2 ч, подождать).
20. Цены и сезоны: изменить цену — в поиске гостя новая цена.
21. Закрыть даты → гостю эти даты недоступны.
22. Продвижение: копирование ссылки, QR-постер печатается, код виджета копируется.
23. «Выйти» в Настройках и на стартовом экране.

## Устройства
24. Android: APK из Releases → android-latest ставится и открывается.
25. iPhone Safari: сайт → «Поделиться» → «На экран Домой» → открывается как приложение.
26. Компьютер: широкий экран, меню сверху, ничего не перекрывается.
27. Без интернета (режим полёта): открывается, показывает «Нет сети».

## Перед переездом на свой сервер
28. Выгрузка базы с Render (`docs/VPS.md`, шаг 4) создаёт файл `voyz.sql`.
29. `SERVER_SECRET` записан в надёжном месте.
30. `ALLOW_DEV_LOGIN=false` на боевом сервере.
